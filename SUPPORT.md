# Support

Start with the [README](README.md) and [changelog](CHANGELOG.md). Downloads and release notes are available on the [Releases page](https://github.com/NeonTideX/OCSJS/releases).

## Bugs and feature requests

Use the [issue forms](https://github.com/NeonTideX/OCSJS/issues/new/choose) and search existing reports first. Include the userscript variant, browser and manager versions, affected integration, reproduction steps, and redacted error logs. Keep answer-provider credentials and private course data out of reports.

Security vulnerabilities belong in [private vulnerability reports](https://github.com/NeonTideX/OCSJS/security/advisories/new), as described in [SECURITY.md](SECURITY.md).

## Contributions and expectations

See [CONTRIBUTING.md](CONTRIBUTING.md). Keep reports focused and provide enough information to reproduce the issue. Maintainers provide support on a best-effort basis; there is no response-time or compatibility guarantee.

The maintained release line is 1.x and development continues on main. Older or modified builds may need to be reproduced against the current release before investigation.
